## Built with

HTML, CSS, and vanilla JavaScript, hosted on GitHub Pages. The design includes a blue and purple gradient, animated stars, responsive layouts, and controls to pause animation.

## Run locally

Clone the repository and serve its root directory:

```bash
git clone https://github.com/ssrid111/portfolio.git
cd portfolio
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).
